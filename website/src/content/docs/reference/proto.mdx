Internal calls between the services use [Connect](https://connectrpc.com/), defined in Protocol Buffers under `proto/` and generated with buf into `gen/`. None of these services is reachable through the gateway.

## LoginService

`user.v1.LoginService` is called only by auth, with its own token: `client_id` `auth`, carrying the `login-codes:redeem` scope. Any other token gets `PERMISSION_DENIED`, even one with the scope. It listens on the user service's `RPC_ADDR`.

<Code {...loginService} />

| Method | Request | Response | Errors |
|---|---|---|---|
| `RedeemLoginCode` | `code`: the code from the sign-in link | `user_id`, `email` | `UNAUTHENTICATED` for an unknown, used or expired code; `PERMISSION_DENIED` for a token not issued to auth |

Generated code:

- [`gen/user/v1/login.pb.go`](https://github.com/vardius/go-api-boilerplate/blob/master/gen/user/v1/login.pb.go): the messages.
- [`gen/user/v1/userv1connect/login.connect.go`](https://github.com/vardius/go-api-boilerplate/blob/master/gen/user/v1/userv1connect/login.connect.go): the Connect client and server interfaces.

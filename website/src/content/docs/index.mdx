## What you start with

<CardGrid>
	<Card title="Event-sourced user service" icon="list-format">
		Users are rebuilt from their own event stream. Event names are versioned, old shapes are upcast, and every
		append checks the stream's version.
	</Card>
	<Card title="Your own token service" icon="padlock">
		OAuth2 with PKCE S256, client credentials and refresh-token rotation with reuse detection. ES256 access
		tokens, verified with the keys it publishes as a JWKS.
	</Card>
	<Card title="Transactional outbox" icon="email">
		Emails are queued in the same transaction as the change that causes them, then delivered at least once
		with backoff.
	</Card>
	<Card title="Three stores, one contract" icon="seti:db">
		Memory, MySQL and MongoDB pass the same contract suite. A build tag picks one per binary.
	</Card>
	<Card title="One command to run" icon="rocket">
		`docker compose up --wait` starts both services and the web app on `localhost:8080`, and Mailpit on
		`localhost:8025`. No cluster, no hosts file.
	</Card>
	<Card title="OpenTelemetry" icon="analytics">
		JSON logs with trace and request IDs. Traces and metrics go out over OTLP once you set an endpoint.
	</Card>
	<Card title="Ready for AI agents" icon="document">
		An `AGENTS.md` in every area, written code standards, and checks that enforce the rules agents tend to
		break.
	</Card>
</CardGrid>
